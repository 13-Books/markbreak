MarkBreak

A Markdown profile for printed matter.

Put the print role in the YAML front matter. Put the hard break on its own line — //break. Leave --- for the scene.

Read the specification GitHub

The name

Mark is Markdown — and the author's mark on a manuscript: this is a chapter, start here. Break is //break: the flow break Markdown never recorded, so a manuscript could not say, in plain text, turn the page.

And yes, we break convention a little — on purpose, and only where convention loses information. Where --- has to double as a page break. Where a heading has to guess a file's print role. Where “new page” is a button pressed in one app, and forgotten by the file.

Everything that already works stays unbroken: still Pandoc Markdown, still readable plain text. The break is small. The manuscript, not the app, gets to say it.

Roles

One file, one role.

---
title: "Commit Don't Push"
role: epilog
---

# After the gates

A second role is a second file.

Breaks

//break advances the story. With one column, that is the next page. //break page forces a page. --- or *** is a pause in the scene.

meta names the publication file. layout names the RigWorks page. Margins and type size stay in that layout file.

Use //break odd or //break even when the page side must be specific.

The check

When you write //break, this fails if Word does not receive that break. Manuscripts are not required to include breaks.
