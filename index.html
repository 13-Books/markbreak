MarkBreak

A Markdown profile for printed matter.

Put the print role in the YAML front matter. Put the hard break on its own line — \newpage or //---. Leave --- for the scene.

Read the specification GitHub

Roles

One file, one role.

---
title: "Commit Don't Push"
role: epilog
---

# After the gates

A second role is a second file.

Breaks

\newpage or //--- starts the next page. --- or *** is a pause in the scene — not a page.

Write a break when you need a hard page. Use //break odd, //break even, or //break column when the advance must be specific.

The check

When you write a flow break, this fails if it does not survive as a real Word page break. Manuscripts are not required to include breaks.
