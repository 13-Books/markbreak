# A Fresh Start

Tables that calculate

A cell that starts with = calculates. Readers see only the results.

| Item   | Qty | Price | Line total   |
|--------|-----|-------|--------------|
| Apples |   2 |     3 |       =B2*C2 |
| Pears  |   4 |     5 | =@Qty*@Price |

Breaks

* * * is a pause in the scene. //break advances the story one column at a time. //break page forces a turn.

Use //break odd or //break even for even more control.

CSV first class

A .csv is a table source with the same calculation dialect. Put it in the spine, or open it alone.

spine:
  - { file: "prices.csv", role: chapter }
